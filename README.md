# 🚗 Road Lane Detection using OpenCV and Keras

## 📌 Overview

This project implements a Road Lane Detection system using OpenCV and Keras. It detects road lane markings from images or video frames using computer vision and deep learning techniques. The project demonstrates image preprocessing, edge detection, and lane identification.

---

## ✨ Features

- Road lane detection from images
- Image preprocessing using OpenCV
- Edge detection
- Lane line identification
- Real-time image processing
- Deep learning with Keras

---

## 🛠️ Technologies Used

- Python
- OpenCV
- Keras
- TensorFlow
- NumPy
- Matplotlib

## ▶️ How to Run

1. Clone this repository

```bash

```

2. Install the required libraries

```bash
pip install opencv-python tensorflow keras numpy matplotlib
```

3. Run the project

```bash
python "ROAD LANE DETECTION PROJECT.py"
```
